## What it does

SeedFuel makes laddus from dry fruits, seeds, dates and homemade ghee, with no added sugar. The home page covers the brand story, ingredients, who it's for, the product, pack sizes, how ordering works, a FAQ and contact. Picking a pack (500 g, 1 kg, 2 kg or 3 kg) opens the order page with that size already selected in the form.

## Features

- **Pack picker.** Size cards link to `order.html?size=1kg`, and the order page highlights the matching card.
- **Pre-filled order form.** The embedded Google Form gets `entry.<id>=<size>` appended, so the pack-size question arrives answered. Picking a different card reloads the form with the new value.
- **WhatsApp ordering.** Every "Order on WhatsApp" button builds a `wa.me` link with a pre-written message that includes the selected size.
- **Config-driven content.** Contact details, prices and form URLs come from `assets/js/config.js`, injected through `data-config` and `data-price` attributes.
- **Visible placeholders.** Any value still unset shows a dashed outline and a tooltip naming the config key to fill.
- **Scroll reveal and sticky order bar.** `IntersectionObserver` drives the reveal animations and a mobile "Order now" bar that appears once the hero scrolls away.

## How it's built

There is no framework and no build step: `index.html`, `order.html` and `404.html`, one stylesheet with the design tokens, and two scripts. `main.js` is a single IIFE in four parts: navigation, scroll reveal, config injection, and the order page logic. Images are served as optimised `.webp`, and the repo includes `sitemap.xml`, `robots.txt` and an Open Graph image. Two docs explain how to build the Google Form and how to edit content and deploy to GitHub Pages.

## What I'd point out

- **Editing without code.** A non-developer changes prices, the phone number or the form by editing one commented file, and the placeholder outline shows what's still missing.
- **Graceful fallbacks.** If no embed URL is set, the order page reveals a fallback block instead of an empty frame, and a share link opens the form in a new tab. Without `IntersectionObserver`, content renders without the animation.
- **Accessible mobile menu.** The menu button keeps `aria-expanded` and its label in sync and closes on Escape.
